# 🎮 Anime Music & Scene Quiz (Arcade Edition)

Desafio interativo de adivinhação de aberturas de animes clássicos e modernos (2000 a 2020) com visualizador espectral de ondas sonoras, multiplayer ao vivo P2P (WebRTC), design Bento Grid responsivo e zero rolagem vertical.

## 🌟 Modos de Jogo
1. **Blind Test (Modo 1):** Ouça a música sem saber o anime e digite seu palpite com autocomplete inteligente (TAB para enviar).
2. **Qual é a Abertura? (Modo 2):** Descubra qual das 3 faixas de áudio é a abertura oficial do anime exibido.
3. **Adivinhe a Cena (Modo 3):** Identifique o anime a partir de capturas de tela e cenas com pistas e zoom dinâmico.
4. **Salas Multiplayer (Modo 4):** Crie salas de desafio em tempo real com amigos usando P2P direto (sem necessidade de servidor central).

## 🚀 Como Executar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador moderno ou rodar um servidor local:
```bash
python -m http.server 8000
```
Acesse: `http://localhost:8000/index.html`
